**Tailwind: Archipelago Flight** is an original zero-dependency WebGL2 3D flight simulation featuring a 6-DOF aerodynamic flight model (angle-of-attack lift, stall buffet, induced drag, retractable gear, flaps, fuel burn, hull damage, and arrestor-wire carrier landings), chase and lit 3D cockpit cameras, an aviation glass HUD, procedural Web Audio SFX, and 4 sorties plus Free Flight.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
